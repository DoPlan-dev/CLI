## Trigger
Exact match: /safe

## Action
When user types /safe:

1. **Security Review**: Security Lead conducts security review
2. **Vulnerability Scan**: Scan for known vulnerabilities
3. **Security Fixes**: Apply security patches and fixes
4. **Response**: "Security review complete. [Number] issues fixed."
