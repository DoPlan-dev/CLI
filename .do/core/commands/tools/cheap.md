# /cheap

## Trigger
Exact match: /cheap

## Action
When user types /cheap:

1. **Cost Optimization**: Review infrastructure and service costs
2. **Optimization Recommendations**: Suggest cost-saving measures
3. **Resource Optimization**: Optimize resource usage
4. **Response**: "Cost optimization complete. Estimated savings: [amount]"

## Agent Involvement
- **DevOps Engineer**: Reviews infrastructure costs
- **Performance Engineer**: Optimizes resource usage
