# Reward System

The Reward System manages how achievements and challenges are awarded, displayed, and celebrated. It ensures rewards are meaningful and motivating.

---

## 🎯 How Rewards Work

### Reward Types

1. **Achievements** - Milestones and accomplishments (10-1000+ points)
2. **Challenges** - High-scoring first-time tasks (300-2000 points)
3. **Score Milestones** - Special achievements for score milestones (100-10,000 points)

### Reward Detection

Rewards are **automatically detected** when you:
- Complete tasks
- Use commands
- Reach milestones
- Complete first-time tasks
- Achieve quality metrics

### No Manual Action

You don't need to:
- Claim rewards
- Enable tracking
- Configure anything
- Do anything special

**Just use DoPlan normally!**

## 📊 Reward Tracking

### View Rewards

```bash
/sys engagement
```

**Shows**:
- Total score (sum of all rewards)
- Achievements earned count
- Challenges completed count
- Last reward time
- Pending rewards (if any)

### Reward History

Rewards are tracked in:
- Memory card (achievements list)
- Engagement dashboard
- Score calculation
