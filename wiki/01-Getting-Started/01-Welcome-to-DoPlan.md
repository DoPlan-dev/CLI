# Welcome to DoPlan

## What is DoPlan?

**DoPlan CLI** is a revolutionary command-line tool that transforms how you start and develop projects. But it's so much more than just a project generator - it's a complete development companion that makes coding **engaging, educational, and fun**.

---

## 🌟 What Makes DoPlan Special?

### 1. **Engagement-First Design** 🎮

DoPlan isn't just a tool - it's an experience. We've built a comprehensive engagement system that makes development exciting:

- **200+ Achievements** - Earn achievements for milestones, learning, and productivity
- **30+ High-Scoring Challenges** - Complete first-time tasks and earn 300-2000 points
- **Score System** - Track your progress from 0 to 100,000+ points
- **Dopamine Timing** - Strategically timed rewards maximize motivation
- **Celebration System** - Multi-achievement bursts create excitement

**Example**: Complete your first API integration and earn:
- 🏆 "API Integration Master" challenge (500 points)
- ✅ "Integration Tested" challenge (750 points)
- 🎯 Score milestone achievement (if you pass 1000 points)
- 🎉 **Total: 1250+ points in one go!**

### 2. **Intelligent Personalization** 🧠

DoPlan learns about you and adapts to your style:

- **Memory Card** - Stores your preferences, learning goals, and relationship data
- **Brain System** - Uses your memory card to personalize every interaction
- **Relationship Building** - DoPlan becomes more friendly and helpful over time
- **Context Awareness** - Remembers your projects, phases, and preferences
- **Tone Adaptation** - Communication style evolves with your relationship level

**Example**: 
- **First time**: "Hello! I'm DoPlan. Let's get started."
- **After 10 projects**: "Hey [Your Name]! 👋 Great to see you again! Ready to build something amazing?"

### 3. **Learning-Focused** 🎓

Whether you're a beginner or professional, DoPlan supports your learning:

- **Beginner-Friendly** - Step-by-step guidance, explanations, test drive mode
- **Learning Goals** - Set and track what you want to learn
- **Educational Explanations** - Understand why, not just how
- **Pain Point Assistance** - Extra help where you struggle
- **Tech Exploration** - Discover and learn new technologies

**Example**: When you use a new technology, DoPlan:
- Explains what it is
- Shows why it's useful
- Provides learning resources
- Tracks it in your learning goals
- Awards achievements for exploration

### 4. **Complete Automation** ⚡

DoPlan automates the tedious parts so you can focus on building:

- **Auto-Commit** - Conventional commit format automatically
- **Auto-Push** - Push to remote without manual commands
- **State Management** - Automatic snapshots and history
- **Time Tracking** - Track everything automatically
- **Git Workflow** - Branch creation, PR suggestions, CI/CD setup

**Example**: When `/dev` detects task completion:
1. Task marked complete in TASKS.md
2. State updated and snapshotted
3. Changes auto-committed: `feat(task-2.1): complete user authentication`
4. Changes auto-pushed to remote
5. PR creation suggested
6. Achievements checked and awarded
7. Duration displayed

### 5. **Comprehensive Tracking** 📊

Know exactly what you're doing and how you're progressing:

- **Time Tracking** - Every command, phase, and task tracked automatically
- **Progress Monitoring** - See completion status, phases, and tasks
- **Engagement Dashboard** - Score, achievements, challenges, relationship level
- **Analytics Ready** - JSONL format for future dashboards
- **State History** - Full history with diff and rollback capability

**Example**: After working on a task:
- See exactly how long you spent: "⏱️ Task duration: 2h 15m"
- View your progress: "Tasks: 5/12 completed (42%)"
- Check engagement: "Score: 1,250 points | Achievements: 8 | Relationship: 45/100"

## 🚀 The DoPlan Workflow

DoPlan follows a simple, powerful workflow:

```
1. /hey    → Onboarding & Tutorial
2. /do     → Capture Your Idea
3. /plan   → Generate Execution Plan
4. /dev    → Start Development (Auto-Detects Completion)
5. /sys status → Check Progress
```

**That's it!** Simple, powerful, and engaging.

## 💡 Key Concepts

Before diving in, here are some key concepts:

### **Memory Card**
Your personal relationship file stored at `~/.doplan/memory_card.json`. It remembers:
- Your preferences and personality
- Learning goals and interests
- Achievements and challenges
- Relationship metrics
- Usage patterns

### **Engagement System**
The system that makes DoPlan fun:
- **Achievements** - Milestones and accomplishments
- **Challenges** - High-scoring first-time tasks
- **Score** - Your total points (0-100,000+)
- **Dopamine Timing** - Strategic reward scheduling

### **Brain System**
The intelligence that personalizes DoPlan:
- Reads your memory card
- Adapts agent responses
- Adjusts tone of voice
- Provides context-aware suggestions

### **State Management**
Tracks your project state:
- Current phase and task
- Completed tasks
- Active branch
- Full history with snapshots
