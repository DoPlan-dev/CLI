## 🎯 Quick Reference

### Workflow Commands
- **`/hey`** - Onboarding, tutorial, welcome
- **`/do`** - Capture idea & discovery
- **`/plan`** - Generate execution plan
- **`/dev`** - Start development and auto-complete tasks

### System Commands
- **`/sys`** - System control panel
  - **`/sys engagement`** - Engagement dashboard
  - **`/sys role`** - Role management
  - **`/sys security`** - Security settings
  - **`/sys control`** - System control

## 🚀 The Workflow

The typical DoPlan workflow:

```
/hey    → Onboarding & Tutorial
  ↓
/do     → Capture Your Idea
  ↓
/plan   → Generate Plan
  ↓
/dev    → Start Development (auto-completes)
  ↓
/dev    → Next Task (auto-completes)
  ↓
...repeat...
```

---

## 💡 Command Philosophy

DoPlan commands are designed to be:

1. **Simple** - Easy to remember and type
2. **Powerful** - Automate complex workflows
3. **Engaging** - Integrated with achievements
4. **Educational** - Provide guidance and explanations
5. **Personalized** - Adapt to your style and preferences
