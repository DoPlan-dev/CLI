# Project Rules

## Rules Library

This directory contains a comprehensive rules library organized by category:

- **01-core-workflow/** - Core development workflow rules
- **02-ai-agents/** - AI agent interaction guidelines
- **03-languages/** - Language-specific rules (Go, Python, TypeScript, etc.)
- **04-frameworks/** - Framework rules (Next.js, React, Express, etc.)
- **05-ui-libraries/** - UI library rules
- **06-cloud-infrastructure/** - Cloud platform rules (AWS, GCP, Azure)
- **07-databases/** - Database rules (PostgreSQL, MongoDB, etc.)
- **08-testing/** - Testing framework rules
- **09-devops-ci-cd/** - DevOps and CI/CD rules
- **10-code-quality/** - Code quality and linting rules
- **11-documentation/** - Documentation standards
- **12-security/** - Security best practices
- **13-development-practices/** - General development practices
- **14-mcp-tools/** - MCP tool integration rules
- **15-project-specific/** - Project-specific rules

## Usage

These rules are automatically loaded by your IDE's AI assistant. The rules are organized hierarchically and cover:

- Coding standards and best practices
- Framework-specific patterns
- Security guidelines
- Testing strategies
- Documentation standards
- And much more!

## Custom Rules

Add your project-specific rules in this directory or create new markdown files that reference the library rules.

## Reference

To reference a specific rule in your commands or agent prompts, use:
@library/03-languages/go/go.md
@library/04-frameworks/frontend/nextjs.md
etc.
