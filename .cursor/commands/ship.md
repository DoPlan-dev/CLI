# /ship

## Trigger
Exact match: /ship

## Action
When user types /ship:

1. **Activate Release Captain**: Prepare for release
2. **Release Checklist**: Run through release checklist
3. **Deployment**: Coordinate deployment with DevOps Engineer
4. **Release Notes**: Generate release notes
5. **Response**: "Release ready! Deployment initiated. Release notes: [link]"

## Agent Involvement
- **Release Captain**: Manages release
- **DevOps Engineer**: Handles deployment
- **QA Engineer**: Final testing
