# /team

## Trigger
Exact match: /team

## Action
When user types /team:

1. **List Active Agents**: Display all active agents in the project with their roles and responsibilities.
2. **Show Hierarchy**: Display the organizational hierarchy showing reporting relationships.
3. **Agent Status**: Show which agents are currently active and their current focus areas.
4. **Response**: Display formatted list of all agents with their roles.

## Agent Involvement
- **Project Orchestrator**: Provides overview of team structure

## Files Read
- .cursor/agents/*.md (all agent files)
