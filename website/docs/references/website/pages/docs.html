DoPlan Documentation

Overview

DoPlan is an enterprise-grade AI-powered development workflow that transforms how you build software. It's not just a tool—it's a complete development system with intelligent agents, comprehensive rules, and powerful automation.

/hey → /do → /plan → /dev

Behind this simple workflow lies a sophisticated system: 18 specialized AI agents, 1000+ embedded rules, automated GitHub workflows, and intelligent project organization.

Why DoPlan?

Interactive Teaching

DoPlan doesn't just execute commands—it teaches you. The /hey command provides personalized tutorials, explains the system architecture, and adapts to your experience level. It's like having a senior developer mentor you through every step.

Automated Organization

Every project is automatically organized into phases, features, and tasks. No more scattered files or confusion about what to build next. DoPlan creates a complete project structure with documentation, prompts, and workflows for each feature.

Intelligent Agents

  • 18 specialized domain experts

The Workflow

/hey - Interactive Onboarding

Your first command! DoPlan doesn't assume you know everything. It teaches you, adapts to your experience level, and creates personalized reference materials.

What makes it powerful:

  • Personalized Experience: Adapts to beginner, intermediate, or advanced developers
  • Interactive Tutorial: Walk through commands with test drives before real execution
  • System Overview: Visual agent hierarchy, workflow explanation, best practices
  • Reference Materials: Auto-generates QUICK_REFERENCE.md, AGENT_HIERARCHY.md, COMMAND_EXAMPLES.md
  • Support Mode Selection: Choose Guided Mode (step-by-step) or Independent Mode

When to use:

First time using DoPlan, or when you need a refresher on capabilities.

/do - Intelligent Discovery

Capture your app idea and automatically start an adaptive discovery meeting. This isn't a static form—it's an intelligent conversation that adapts to your project type and experience level.

Usage:

/do
/do app idea prompt
/do app idea prompt "Build a task management app"

What makes it powerful:

  • Adaptive Interview: Questions change based on project type (SaaS, Mobile App, Website, etc.)
  • Speed Options: Quick Start (5-10 min), Standard (15-20 min), Comprehensive (30-45 min), Deep Dive (60+ min)
  • Experience-Based: Beginner-friendly or deep technical discussions
  • Phase-by-Phase: 6 comprehensive phases covering vision, audience, UX, content, marketing, delivery
  • Progress Tracking: Real-time progress bars, timing information, phase summaries
  • Content Planning: Automatically identifies content needs (legal pages, blog, SEO, etc.)
  • GitHub Integration: Verifies and sets up GitHub workflows during discovery

When to use:

When you have a new project idea or want to start a discovery session.

/plan - Comprehensive Planning

Generate complete planning documents, execution plans, and content. This command has extensive subcommands that make it incredibly powerful.

Usage:

/plan                    # Generate planning docs (first time) or show menu
/plan docs               # Generate PRD, Architecture, Design System
/plan tasks              # Generate execution plan and tasks
/plan everything         # Generate all planning docs + execution plan
/plan content            # Generate content (app pages, legal, blog, etc.)
/plan edit prd Add dark mode  # Edit existing documents
/plan phases             # Plan phase by phase
/plan next               # Plan next phase
/plan phase 1 tasks      # Create tasks for specific phase

What makes it powerful:

  • Complete Documentation: PRD.md, ARCHITECTURE.md, DESIGN_SYSTEM.md generated by specialized agents
  • Automated Organization: Creates phase folders (01-Foundation, 02-Core, 03-Enhancement)
  • Feature Folders: Each feature gets design.md, plan.md, tasks.md, prompts.md, github.md
  • Content Generation: SEO-ready app pages, legal documents, blog posts, marketing content
  • Document Editing: Natural language editing (e.g., "Add dark mode")
  • Flexible Planning: Full planning, phase-by-phase, or selective updates

When to use:

After completing the discovery meeting (/do).

/dev - Intelligent Development

Start coding with full context, automatic branch management, and intelligent task tracking.

Usage:

/dev        # Start next uncompleted task
/dev 1.2     # Start specific task 1.2
/dev 3       # Start task 3

What makes it powerful:

  • Automatic Branching: Creates task/1.2 branches automatically
  • Agent Activation: Automatically activates relevant agents (Frontend Lead, Backend Lead, etc.)
  • State Snapshots: Automatic state tracking for rollback capability
  • Task Context: Loads complete task documentation, dependencies, and related code
  • Auto-Detection: Agents detect task completion and prompt for confirmation
  • Git Safety: Ensures clean working tree before starting

When to use:

After planning is complete (/plan), ready to start coding.

System Commands

While DoPlan has only 5 main commands, the power lies in the 15+ subcommands that make each command incredibly versatile.

/sys - System Management

All system-related operations consolidated under one powerful command. This is where DoPlan's automation really shines.

Subcommands:

/sys status

Progress Tracking: Shows task completion, current phase, progress percentage, state deltas. Generates comprehensive scan reports with metadata and diffs.

/sys status - Show progress
/sys status report - Generate scan report
/sys status full - Progress + report
/sys optimize

Multi-Domain Optimization: UI/UX improvements, cost analysis, performance optimization. Agents analyze and provide actionable recommendations.

/sys optimize design - UI/UX improvements
/sys optimize finance - Cost optimization
/sys optimize performance - Performance tuning
/sys optimize all - Run all optimizations
/sys access

Permission Management: Fixes permissions and creates missing folders. Ensures DoPlan can write reference docs and state files.

/sys github

GitHub Automation: Complete GitHub workflow automation. Sync README, create issues, manage milestones, generate CI/CD workflows, plan releases.

/sys github info - Sync README with KPIs
/sys github issue - Create formatted issues
/sys github ci - Generate CI/CD workflows
/sys github release - Release management
/sys role

RBAC Design: Security Lead and Backend Lead design complete role-based access control systems with role definitions and permissions.

/sys control

System Control Panel: Toggle agents, roles, or the entire DoPlan automation layer on/off. Use it to pause operations during maintenance or incidents.

/sys control agents on/off – Enable or disable all agents
/sys control roles on/off – Activate or deactivate specific role groups
/sys control system on/off – Kill switch for the entire DoPlan system (requires multi-step confirmation)
/sys security

Security Operations: Comprehensive security review and audit. Vulnerability assessment, compliance checking, security report generation.

/sys security review - Security review
/sys security audit - Full security audit
/sys security - Show security menu
/sys state

State Management: Complete state snapshot system for audit trails and rollback capability. Track every change, compare states, restore when needed.

/sys state snapshot - Create snapshot
/sys state list - List snapshots
/sys state diff - Compare states
/sys state restore - Restore state

GitHub Integration

Complete GitHub workflow automation. Set up professional CI/CD pipelines, manage releases, and maintain repository health—all with simple commands.

Automated CI/CD

One command sets up your entire CI/CD pipeline:

/sys github ci

This generates GitHub Actions workflows that:

  • Run tests on every branch
  • Lint code automatically
  • Build binaries for multiple platforms
  • Enforce branch protection policies
  • Support branch-based job matrices

Repository Management

Keep your repository in sync with your project:

/sys github info

Automatically:

  • Syncs README with project KPIs from PRD
  • Updates repository metadata
  • Shows project health metrics
  • Maintains offline metadata cache

Issue & Milestone Management

/sys github issue "Title" "Description"
/sys github milestone "MVP"

Creates properly formatted GitHub issues and milestones with links to project documentation.

Release Automation

/sys github release

Complete release management:

  • Version management and semantic versioning
  • Automatic release note generation from CHANGELOG
  • Deployment planning
  • Release workflow automation

Getting Started

  1. Install: npx @doplan-dev/cli init
  2. Learn: Type /hey for interactive onboarding
  3. Start: Type /do to capture your idea and begin discovery
  4. Plan: Type /plan to generate all planning documents
  5. Build: Type /dev to start development

That's it! No configuration needed. DoPlan handles project structure, documentation, GitHub workflows, and organization automatically.
