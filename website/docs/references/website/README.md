# DoPlan Website

Website and documentation for [doplan.dev](https://doplan.dev)

## Structure

```
website/
├── index.html              # Landing page
├── pages/
│   └── docs.html          # Documentation page
├── assets/
│   ├── css/
│   │   ├── style.css      # Main styles
│   │   └── docs.css       # Documentation styles
│   ├── js/
│   │   └── main.js        # JavaScript functionality
│   └── images/            # Images and assets
└── README.md              # This file
```

## Features

- **Landing Page** (`index.html`)
  - Hero section with workflow visualization
  - Features showcase
  - Workflow explanation
  - Commands overview
  - Get started section

- **Documentation** (`pages/docs.html`)
  - Complete command reference
  - Workflow explanation
  - Examples and usage
  - Getting started guide

## Deployment

The website is ready to be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service

## Development

1. Open `index.html` in a browser for local development
2. All assets are relative paths, so it works locally
3. No build step required - pure HTML/CSS/JS

## Customization

- Update colors in `assets/css/style.css` (CSS variables)
- Modify content in HTML files
- Add more pages in `pages/` directory
- Update navigation in all HTML files

## Branding

- Domain: **doplan.dev**
- Workflow: **Hey → Do → Plan → Dev**
- Primary Color: Indigo (#6366f1)
