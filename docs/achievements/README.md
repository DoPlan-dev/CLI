# DoPlan Achievements

Welcome to the DoPlan Achievement System! This directory contains comprehensive documentation about all achievements you can earn while using DoPlan.

## Overview

DoPlan features **200+ achievements** across 9 categories, designed to motivate and celebrate your development journey. Each achievement you earn contributes to your total score and helps build your relationship with DoPlan.

## Achievement Categories

1. **[Score Milestones](./ACHIEVEMENTS.md#score-milestones)** - Reach point thresholds (10 achievements)
2. **[Project Achievements](./ACHIEVEMENTS.md#project-achievements)** - Complete projects and milestones (30+ achievements)
3. **[Command Usage](./ACHIEVEMENTS.md#command-usage-achievements)** - Master DoPlan commands (20+ achievements)
4. **[Learning Achievements](./ACHIEVEMENTS.md#learning-achievements)** - Expand your knowledge (20+ achievements)
5. **[Productivity Achievements](./ACHIEVEMENTS.md#productivity-achievements)** - Build consistent habits (20+ achievements)
6. **[Streak Achievements](./ACHIEVEMENTS.md#streak-achievements)** - Maintain daily usage (15+ achievements)
7. **[Relationship Achievements](./ACHIEVEMENTS.md#relationship-achievements)** - Build your partnership (15+ achievements)
8. **[Milestone Achievements](./ACHIEVEMENTS.md#milestone-achievements)** - Collect achievements (20+ achievements)
9. **[Special Achievements](./ACHIEVEMENTS.md#special-achievements)** - Unique moments and events (30+ achievements)

## How to Earn Achievements

Achievements are automatically checked and awarded when you:
- Complete commands (`/do`, `/plan`, `/dev`, `/done`)
- Reach milestones (score thresholds, project counts)
- Use DoPlan consistently
- Learn new technologies
- Build your relationship with DoPlan

## Viewing Your Achievements

- **In CLI**: Use `/sys engagement` to see your achievement dashboard
- **In IDE**: Achievements unlock during development and appear as notifications
- **Documentation**: See [ACHIEVEMENTS.md](./ACHIEVEMENTS.md) for the complete list

## Achievement Rarities

- **Common** 🟢 - Easy to earn, frequent unlocks
- **Uncommon** 🔵 - Moderate difficulty
- **Rare** 🟣 - Significant milestones
- **Epic** 🟠 - Major accomplishments
- **Legendary** 🔴 - Ultimate achievements

## Graphics

Achievement graphics are available in the [graphics/](./graphics/) directory. Each achievement has a corresponding PNG image file named `{achievement_id}.png`.
