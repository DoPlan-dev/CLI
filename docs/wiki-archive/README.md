# Archived Wiki Files

This directory contains the old flat wiki files that were used for GitHub Wiki.

These files have been replaced by the new hierarchical wiki structure in `../wiki/`.

## Structure

The new wiki structure is organized into numbered sections:
- `01-Getting-Started/` - Getting started guides
- `02-Commands/` - Command documentation
- `03-Engagement-System/` - Engagement features
- `04-Memory-and-Brain/` - Memory and personalization
- `05-Workflow/` - Workflow guides
- `06-Features/` - Feature documentation
- `07-Learning-Education/` - Learning resources
- `08-Advanced/` - Advanced topics
- `09-Reference/` - Reference documentation

## GitHub Wiki

The flat files in this archive are still used for GitHub Wiki (which doesn't support subdirectories).
