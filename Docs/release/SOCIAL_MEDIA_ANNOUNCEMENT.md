Hey r/programming!

I'm excited to share DoPlan CLI v1.0.0 - a command-line tool that generates professional project structures with a complete hierarchical AI agency system.

**What it does:**
- Interactive TUI wizard for project creation
- 18 specialized AI agents (Project Orchestrator, Engineering Lead, Frontend Lead, etc.)
- 500+ embedded rules for all major tech stacks
- Complete automation with 19 commands
- Cross-platform support (macOS, Linux, Windows)

**Quick start:**
```bash

**Key features:**
- Zero-install experience via npx
- Beautiful Bubbletea-powered TUI
- Complete project structure generation
- GitHub workflows, IDE configs, documentation templates
- Next.js boilerplate included
- Binary size: 8.2MB, generation time: < 50ms

**Built with:**
- Go 1.21+
- Bubbletea (TUI framework)
- Cobra (CLI framework)

**GitHub:** https://github.com/DoPlan-dev/CLI

## Tips for Posting

1. **Timing:**
   - Post during peak hours for your audience
   - Consider time zones
   - Avoid weekends (unless targeting specific communities)

2. **Engagement:**
   - Respond to all comments quickly
   - Thank early adopters
   - Address concerns promptly

3. **Visuals:**
   - Include screenshots of the TUI
   - Create a demo GIF/video
   - Use consistent branding

4. **Hashtags:**
   - Use relevant, popular hashtags
   - Don't overuse (3-5 per post)
   - Research hashtag popularity

5. **Cross-posting:**
   - Adapt content for each platform
   - Don't copy-paste verbatim
   - Respect each platform's culture
