# GoPlan-CLI

Generated by [DoPlan](https://github.com/dorgham/doplan) - Zero-install AI Project Director

## Quick Start

1. Open this project in your IDE (Cursor)
2. Type /tell to capture your project idea
3. Follow the commands below to build your project

## Commands

### Core Commands

- **/tell** → Capture your project idea
- **/improve** → Team brainstorm session
- **/team** → Show active agents and hierarchy
- **/write** → Generate PRD + ARCHITECTURE + DESIGN_SYSTEM
- **/change** → Edit any document (e.g., /change prd Add dark mode)
- **/good** → Approve & lock the plan
- **/tasks** → Generate TASKS.md from approved plan
- **/load** → Inject context into AI agents
- **/build** → Start coding next task (or /build 3 for specific task)
- **/progress** → Show current progress
- **/finished** → Mark current task done

### Squad-Specific Commands

- **/ship** → Release management
- **/safe** → Security audit
- **/cheap** → Cost optimization

## Workflow

1. **Idea** → Type /tell to capture your idea
2. **Brainstorm** → Type /improve to brainstorm with the team
3. **Plan** → Type /write to generate all planning documents
4. **Approve** → Type /good to approve and lock the plan
5. **Tasks** → Type /tasks to generate implementation tasks
6. **Code** → Type /build to start coding
7. **Progress** → Type /progress to see how you're doing
